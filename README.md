🎬 Movie Ticket Booking Calculator (Python)
📖 Overview
This beginner-friendly Python project calculates movie ticket charges based on:
Age category (child, adult, senior)
Seat type (regular, premium, VIP)
Membership status (discounts for members)
Weekend pricing
Show timing (matinee vs evening)
It uses conditional statements to simulate a real-world ticket booking system, making it a great practice project for learning Python basics.

🚀 Features
Age-based ticket eligibility and pricing
Different seat categories with variable costs
Membership discounts applied automatically
Weekend surcharge handling
Simple, interactive console-based input/output

🛠️ Technologies Used
Python 3.x
Conditional statements (if-elif-else)
Basic input/output functions

How to Run
Clone the repository:
git clone https://github.com/harshkumargupta016-a11y/movie-ticket-booking-calculator-python.git

Navigate to the project folder:
cd movie-ticket-booking-calculator-python

Run the script:
python main.py
